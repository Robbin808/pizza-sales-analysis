# Pizza Sales Analysis

A compact **SQL business-analysis project** built around translating operational questions into structured queries and measurable sales insights.

## Project Focus

The analysis progresses from basic business KPIs to more advanced revenue and category analysis. The question set covers:

- total orders and total revenue
- highest-priced pizza
- most common pizza size
- top-selling pizza types by quantity
- category-level quantity distribution
- hourly order patterns
- average pizzas ordered per day
- top pizza types by revenue
- revenue contribution by pizza type
- cumulative revenue over time
- top revenue-generating pizzas within each category

## Repository Contents

- `Questions.txt` — the business questions used to structure the SQL analysis
- `sql pizza sales project.zip` — packaged project material containing the analysis resources
- `Black and Yellow Modern Pizza Sale Video.mp4` — presentation/demo asset

## What This Project Demonstrates

- converting business questions into SQL analysis tasks
- aggregation, grouping, joins, ranking, and revenue analysis
- moving from descriptive KPIs toward comparative and time-based insights
- organizing a small analytics project around a clear question hierarchy

## Analysis Structure

```text
Business question
      ↓
Relevant tables / fields
      ↓
SQL query
      ↓
Validation of result
      ↓
Business interpretation
```

The project is intentionally organized from **basic → intermediate → advanced** questions so that the analysis develops from core KPIs into deeper category and revenue patterns.
